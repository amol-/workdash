Keep your tools connected

You and your agents use the same work items, worktrees, and panes instead of separate workflows.

Text is the common language, inspired by Unix pipes. Zellij is the coordination bus: workdash sends text into a pane and reads text back. You can inspect and interact with that same pane yourself.

  1. Pick an issue. Read its discussion and choose an agent from the code menu.
  2. Start in its worktree. Your chosen agent opens in a pane with the work item's context.
  3. Read and respond. Watch the pane and send input, or stop the agent and continue in its worktree yourself.
  4. Review the result. Inspect the changes before deciding what to do with the pull request.

An assistant using the CLI can inspect and interact with the same work. Use the pane ID from workdash info in place of PANE_ID: 

workdash info
workdash read PANE_ID
workdash write PANE_ID "Run the tests before continuing."

You read what the agent printed, then send it text as input. How it responds depends on the tool running in that pane.

  • Bring your own tools. Keep your editor, agents, terminal tools, and scripts in Zellij panes alongside the dashboard.
  • Replace the defaults. Start with detected agents and the built-in document viewer, then configure your preferred commands.
  • Match the action. Configure an analysis command, a coding command, or both for each agent; each receives the task prompt as its last argument.
  • Skip special integrations. Compatible text-driven tools need no workdash-specific plugin, extension, skill, or dedicated agent harness.

Start with your own workspace

Install with uv to put workdash on your PATH in an isolated environment. 

uv tool install workdash

Configure your GitHub account, repositories, agents, and working directory through the setup wizard. 

workdash --configure

Start your dashboard in Zellij, then keep it running while you use the CLI. 

workdash

What you need installed

You can run workdash on Linux or macOS with the following tools.

  • Python 3.12+. You need Python 3.12 or later to run workdash.
  • GitHub CLI. Authenticate gh with gh auth login so you can access your repositories.
  • Zellij. You use zellij for the dashboard, terminal panes, and agent sessions.
  • A terminal that runs Zellij. You can use ptyxis, konsole, Ghostty, or any terminal that runs Zellij well.
  • A link opener. Use xdg-open on Linux or open on macOS for GitHub links and external links from documents.
  • Your choice of agents. Setup requires one configured agent; choose claude, codex, pi, or another compatible command.
  • Optional tools, per action. Use your agents for analysis or coding, and optionally install code to launch VSCode Copilot from the code menu.

The setup wizard can install local copies of gh and zellij if you do not have them.
