Make it yours

Bring your own agent

Use Claude Code, Codex, pi, or another terminal agent. Pick one to brief you on an issue, and another to write the code.

Your agent opens in the issue’s Git worktree with the task in hand. Open a terminal in that same worktree to inspect the changes or take over.

Bring your own tools

Unix pipes let one tool use another’s output because both speak text. workdash takes the same idea into Zellij, the terminal workspace you share with your agents.

workdash sends tasks as text and reads what your tools print. You can swap in a compatible agent, viewer, or script without waiting for a plugin.

Keep the editor you already use. Open the same checkout in it whenever you want to make a change yourself.
